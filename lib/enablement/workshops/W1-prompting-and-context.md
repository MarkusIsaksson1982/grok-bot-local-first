# W1 - Prompting and context for development teams (90 min)

**Goal:** the team writes one repository instructions file and three reusable prompts for its own daily tasks.

| Time | Part | What happens |
|---|---|---|
| 0-10 | Why context beats clever prompts | Live demo: the same task with and without project context |
| 10-30 | Instructions files | Write the repo's coding conventions, test commands and "never do" list into the instructions file the team's assistant reads |
| 30-60 | Exercise on real tickets | Pairs take a real ticket; prompt, review the diff, note what the assistant got wrong |
| 60-80 | Limits and safe use | Hallucinated APIs, outdated libraries, secrets in prompts, licence questions; the verification levels V1-V3 |
| 80-90 | Into the library | Each pair adds one prompt to the shared library; champion collects feedback |

Exercise variants: junior developers (explain unfamiliar code), testers (derive test cases from acceptance criteria),
senior developers (refactor plan with a rollback).
