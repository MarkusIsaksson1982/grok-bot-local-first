# Release notes from merged PRs

1. List the merged PRs for the release (title, labels, linked issue).
2. Group them as New, Improved, Fixed. Skip internal refactors unless they change behaviour.
3. Write one sentence per item for a non-technical reader. No ticket numbers in the text.
4. Mark anything you are unsure about with `[check]` instead of guessing.
5. Follow the template in [template.md](template.md).

Verification: a person reads every line against the PR before the notes are shared.
