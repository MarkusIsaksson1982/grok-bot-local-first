# web-chat-openai (ChatGPT web)

- Paste `prompts/common.md` "Ask preamble" + task. Set `source: web-chat-openai`.
- Attach all files in the first message that refers to them; later attachments are often ignored.
- Use the copy button on the reply; it may wrap it in one fence (ret-lint strips that).
- Same thread only if the ask depends on the previous reply; otherwise start a new chat.
